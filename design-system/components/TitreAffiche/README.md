# TitreAffiche

Le bloc titre d'une affiche : un mot clé en `titre-impact` (Anton, capitales), une annotation manuscrite qui le chevauche et un trait de pinceau qui le souligne.

**Ce que vous fournissez :** 1 à 3 mots pour le titre, au plus 3 mots pour l'annotation, le sous-titre éventuel.

**Recette Photoshop**
- Titre : Anton, 220 px pour 1080 px de large, interlignage 86 %, approche -10. Couleur `titre` (bleu électrique sur blanc, blanc sur bleu).
- Annotation : Caveat Brush, 76 px, rotation -6°, posée sur le coin haut gauche du titre. Couleur `titre`, jamais orange sur bleu électrique (contraste trop faible).
- Trait : `trait-pinceau-orange.svg` sur fond bleu, `trait-pinceau-bleu.svg` sur fond blanc, calé sous la dernière ligne.

**À faire**
- Un seul titre par affiche. Mot de plus de 9 lettres : passez à `titre-impact-m`.
- Pour un ton plus posé, remplacez le titre Anton par `titre-large` (Plus Jakarta Sans 800), jamais les deux ensemble.

**À éviter**
- Dégradé, contour, lueur ou effet 3D sur les lettres.
- Plus d'une annotation manuscrite par affiche.
