# Etiquette

Les petites étiquettes qui rangent l'information : catégorie, urgence, niveau, édition.

**Ce que vous fournissez :** 1 à 3 mots. Les étiquettes rectangulaires sont en capitales (`etiquette`), les pilules en casse normale.

**Variantes**
- `.cie-etiquette` : bloc bleu nuit, texte blanc, angles vifs (`rayon-0`). Catégorie ou thème.
- `.cie-etiquette--accent` : bloc orange, texte `encre`, ombre décalée `ombre-dure`. Réservée à l'urgence (Places limitées, Gratuit, Dernier jour). Une seule par affiche.
- `.cie-etiquette--blanche` : sur fond bleu ou sur photo.
- `.cie-pilule` : contour 3 px, pour l'édition ou le numéro d'atelier, en haut à droite.
- `.cie-pilule--pleine` : aplat `fond-alt`, pour un hashtag.

**À éviter**
- Texte blanc sur orange (2,7:1, illisible).
- Plus de 3 étiquettes sur une même affiche.
