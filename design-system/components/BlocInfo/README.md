# BlocInfo

Les infos pratiques (quand, où, comment) en barres empilées : un carré orange avec l'icône, une barre `fond-alt` avec le texte.

**Ce que vous fournissez :** pour chaque ligne une icône, une info principale (`b`, en capitales) et un détail (`small`).

**À faire**
- 2 ou 3 lignes au plus, dans l'ordre : date, lieu, heure ou lien.
- Dates au format court : « Sam. 18 oct. », heures « 09h00 à 12h00 ».
- Icônes : Phosphor, graisse Bold, en `encre` sur l'orange.
- Placez le bloc dans le tiers bas de l'affiche, aligné à gauche sur `marge-affiche`.

**À éviter**
- Mettre la date dans le titre.
- Des icônes en couleur ou en 3D.
