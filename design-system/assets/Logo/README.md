# Logo

- `logo-cie-pastille.png` : la pastille ronde, fond transparent autour du cercle. À utiliser partout (en-tête, bandeau).
- `logo-cie-original.jpg` : le fichier d'origine, carré, fond blanc.

Les deux sont des images de 200 px à l'origine : suffisantes pour les réseaux sociaux à 88 px, trop petites pour l'impression A3. Une version vectorielle (SVG, AI ou PDF) est à retrouver ou à redessiner fidèlement.
