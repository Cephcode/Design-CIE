# Textures

- `grain-photoshop.png` : bruit monochrome de 512 px, à répéter (Motif) en mode Incrustation, 8 à 12 %. Sur tous les fonds.
- `trame-circuit-seule.svg` : les pistes de circuit seules, encre `bleu-nuit`, à poser sur un fond clair à 6 % d'opacité.
- `trait-pinceau-orange.svg`, `trait-pinceau-blanc.svg`, `trait-pinceau-bleu.svg` : coup de pinceau qui souligne le titre. Orange ou blanc sur fond bleu, bleu sur fond blanc.
